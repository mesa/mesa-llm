# Tutorials

Step-by-step guides to learn Mesa-LLM by building working models. Start with your skill level:

## Beginner Tutorials

### [Creating Your First Model](first_model.md)

**Time**: 30 minutes
**Prerequisites**: Python basics, Mesa fundamentals
**You'll learn**:

- How to create a simple LLMAgent
- Basic ReAct reasoning
- Running a minimal Mesa-LLM model
- Printing agent reasoning output

**Good if**: You're new to Mesa-LLM or want a quick overview

---

## Intermediate Tutorials

### [Negotiation Model](negotiation_model_tutorial.md)

**Time**: 1-2 hours
**Prerequisites**: First Model tutorial
**You'll learn**:

- Multi-agent reasoning
- Agent-to-agent communication
- Memory systems for context
- Negotiation strategies

**Good if**: You want agents to interact dynamically

---

## Tutorial Progression

```
1. Start → First Model (basic concepts)
   ↓
2. → Negotiation Model (multi-agent)
   ↓
3. → Examples (study working models)
   ↓
4. → Build your own!
```
